# 📱 Mobile App (Expo / React Native)

> 🚧 À venir en **Vague 2**

Cette application contiendra les 3 apps consommateurs (Parent / Enseignant / Direction)
construites avec **Expo SDK 51+** et **React Native**.

## Stack prévue

- Expo SDK 51+
- React Native 0.74
- Expo Router (file-based routing)
- NativeWind (Tailwind pour RN)
- Zustand (state)
- TanStack Query (data fetching)
- Expo Notifications (push)

## Setup à venir

```bash
cd apps/mobile
pnpm install
pnpm dev # ouvre le QR code Expo Go
```
