# Vague 1.5 — Recovery & Invite-only Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship password recovery, email verification, invite-only registration, user profile, RGPD data export, cookie consent, Sentry boot, and i18n infrastructure. Switch Prisma from `db push` to `migrate` (R1 mitigation).

**Architecture:** Add 3 new entities (`EmailVerificationToken`, `PasswordResetToken`, `InviteToken`), 2 columns on `User` (`emailVerifiedAt`, `passwordChangedAt`), nullable `RefreshToken.tenantId` for super_admin support. Add NestJS modules `admin/`, `users/`, `common/email/`, `common/r2/`, `common/sentry/`. Add web pages `/forgot-password`, `/reset-password`, `/verify-email`, `/profile`. Wire Resend + Sentry + Cloudflare R2 (all free tier, $0/mo).

**Tech Stack:**
- Prisma 5 migrations (`prisma migrate`)
- Resend (`resend` npm + `@react-email/components`)
- Cloudflare R2 (`@aws-sdk/client-s3`)
- Sentry (`@sentry/nestjs`, `@sentry/nextjs`)
- next-intl (web i18n)
- Existing Vague 1 stack (NestJS 10, Next.js 14, Postgres Neon, shadcn/ui)

  const id = createId();

  return { id, token: plaintext, url: `${baseUrl}/register?token=${plaintext}`,

           expiresAt: expiresAt.toISOString() };
